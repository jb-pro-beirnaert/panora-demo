# V11 — Finitions pour la candidature

**Résultat attendu** : Panora peut comprendre le projet en 2 minutes et le tester en ligne.

## Livrables

- **README** (en anglais, avec un résumé en français) :
  - le problème et le parcours d'un dossier ;
  - l'architecture (schéma) ;
  - les choix et leurs compromis : microservices, trois agents, Mastra en mode framework, prompts en anglais pour une démo bilingue, Langfuse auto-hébergé ;
  - les résultats chiffrés : evals, coûts, charge ;
  - comment lancer le projet (`npm install`, `npm run dev`).
- **Vidéo de 2 minutes** : on démarre le flux, un e-mail arrive, la timeline se remplit, le courtier valide, l'audit ; bascule FR / EN ; puis l'écran Evals et le tableau des coûts.
- **Déploiement** sur un VPS (`npm run start:docker`, Dokploy), avec des comptes de démo et le panneau de démo accessible.
- **Message à Panora** : Doctoride comme projet dont tu es fier, la démo présentée honnêtement comme une démo construite pour eux.

## Critères d'acceptation

- [ ] Une personne qui ne connaît pas le projet le lance en local avec deux commandes.
- [ ] La démo en ligne fonctionne avec un compte de démo.
- [ ] La vidéo dure 2 minutes au plus.
